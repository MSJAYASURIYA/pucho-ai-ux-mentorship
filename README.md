# Pucho.ai UX Mentorship Submission

A complete concept case study for the mentorship brief: an outcome-first, human-controlled AI workflow for a non-technical operations lead.

## Files

- `Pucho_AI_UX_Case_Study.pdf` - presentation covering discovery, strategy, information architecture, flows, wireframes, visual system, key UI, interaction states, prototype, and validation plan.
- `Pucho_AI_Clickthrough_Prototype.html` - self-contained clickthrough. Open in a modern browser; no install, login, network access, or external assets are needed.
- `Research_and_Validation_Kit.md` - evidence register, interview guide, recruitment notes, three moderated test tasks, measures, and iteration log.

## Project status

The concept, design artifacts, and runnable prototype are complete. The persona is a proto-persona, and user needs are hypotheses. Public product and competitor pages were reviewed on 27 October 2026. No primary interviews or participant usability sessions were conducted for this submission. The validation kit is ready to run; the deck does not present invented participant findings or measured impact.

## Prototype route

Build request -> AI plan -> access review -> sample preview -> run status and approval queue. Use the progress buttons or primary buttons to move through the route. The top and side navigation are interactive. All data and actions are fictional demo content; the prototype does not connect to Pucho, a CRM, Slack, or any other service.

## Design intent

The experience follows five principles: intent before configuration, explain before execute, preview before commit, human control at consequential moments, and recover without fear. The workflow reads CRM fields, drafts a Slack summary, and pauses for human approval before posting.
