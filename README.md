# Pucho.ai UX Mentorship Project

**Concept case study:** Trust-first AI automation for non-technical users.

This independent concept explores how a first-time user can describe a business outcome, review a proposed workflow, inspect app permissions, preview an action, and stay in control before consequential actions happen. It is a UX concept, not an official Pucho.ai interface or a claim about shipped product features.

## Deliverables

- **Pucho_AI_UX_Case_Study.pdf** — 20-page case study covering the problem, research approach, persona hypothesis, JTBD, HMW, information architecture, user flow, wireframes, visual direction, high-fidelity screens, prototype plan, and validation plan.
- **index.html** — interactive front-end concept. Download and open in a modern browser, or publish with GitHub Pages.
- **interview_guide.md** — interview questions and the current evidence log.
- **competitor_audit.md** — desk audit of publicly available official product pages.
- **usability_test_plan.md** — proposed tasks and observations for validating the prototype.

## Design direction

**Ask → Plan → Review access → Preview → Run demo → Inspect result / recover**

The concept emphasizes plain-language setup, a readable plan, clear permissions, a preview, approval before consequential actions, and understandable run status.

## Prototype limitations

- The prototype is a scripted UI simulation; it does not use a live AI model.
- No external accounts or integrations are connected.
- No real records are read and no messages are sent.
- Preview data is fictional.

## Research status and limitations

One proxy participant identified **studying** as a repeated task. This is not target-user evidence from a business operations manager. The other answers shown as examples during planning are not treated as participant quotes or validated findings. The persona and design opportunities are hypotheses pending further interviews. Usability sessions have not yet been conducted; the test plan is included so the design can be validated rather than claiming tests that did not occur.
